## ChangeLog

相对 v1.0.0，这一版先把版本号、签名和发布门禁做实，并补齐压缩包解压缺口。

### 版本

- 单一来源：`gradle.properties` 的 `OPENCONVERT_VERSION_NAME` / `OPENCONVERT_VERSION_CODE`
- Basic：`1.1.0` / `1100`
- Office：`1.1.0-office` / `1101`
- Tag 必须等于 `1.1.0`，否则 CI 失败
- PHY110 debug：`100` office → `1100` Basic → `1101` Office，未加 `adb -r` 即可覆盖

### 签名

- v1.1 使用 v2 证书（SHA-256 见下方下载表，由本次构建写入）
- 口令曾进入 git 历史，jks 从未入库或上架
- **已安装 v1.0.0 的用户不能覆盖升级，必须卸载重装**（本地历史会丢）

### 压缩包

- 补齐裸 TAR / GZIP / BZIP2 解压（原先只能压）
- 新增 XZ 单文件压缩 / 解压，以及 TAR.XZ / `.txz` 解压
- 选择器放开 7Z

### 体积与引擎

- FFmpegKit 从 `full` 换成 `audio`（H.264 走 Media3，VP8 走 LiTr）
- 具体 APK / AAB 大小以本次构建写入的下载表为准，不再手写

### CI

- hosted x86_64 emulator smoke（Java / Room / Compose，不含原生转换）
- Tag 缺 Secret、unsigned、错证、错版本、非 arm64 → 不创建 Release
- Actions 钉到 commit SHA；仅 publish job 有 `contents: write`

## 安装摘要

1. 只要图片 / 音视频 / PDF / 压缩包 → 装 Basic。还要 Word / PPT / Excel 转 PDF → 装 Office。
2. 用 Release 附件里的 `SHA256SUMS.txt` 核对哈希，不要抄旧版表格。
3. 允许「安装未知应用」后打开 APK。
4. 从 v1.0.0 升级：先卸载再装。同为 v1.1 时 Basic → Office 可直接覆盖。

## 已知问题

- 仅 arm64-v8a
- 已装旧证 v1.0.0 无法被本版覆盖
- Dynamic Feature、4GB 视频仍按产品决定延期
- 无 PDF 水印；Office 图表 / 嵌入对象 / 受保护文档未做内容级门禁
- 默认文案仍是中文，还没有 `values-en`
