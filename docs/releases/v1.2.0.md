## ChangeLog

相对 v1.1.0：同一把 v2 证书，`versionCode` 升高，已装 1.1.0 的用户可以直接覆盖。计划书 §十五 的开源 / 国际化 / CI / LFS 工作记入本版。

### 版本

- Basic：`1.2.0` / `1200`
- Office：`1.2.0-office` / `1201`
- Tag 必须等于 `1.2.0`，否则 CI 失败

### 升级

- v1.1.0 → v1.2.0：同证覆盖，历史 / 预设 / SAF 保留
- 已装旧证 v1.0.0 仍须先卸载再装

### 国际化

- 默认中文；系统语言为 English 时核心流程走 `values-en`
- `AppCopy` + zh/en 键对等
- [README_EN.md](https://github.com/donalaaaaaaa/OpenConvert/blob/main/README_EN.md)

### 开源治理

- `SECURITY.md` / `CONTRIBUTING.md` / `CODE_OF_CONDUCT.md`
- Issue / PR 模板；Dependabot（Actions + Gradle）

### CI 与仓库

- hosted emulator smoke：API 31 / 34 / 36（x86_64，不含原生转换）
- 普通 PR 不拉 LFS、不 assemble；main / tag / 真机才拉 native
- NDK zip 出树，改走 `native/deps.lock` + `scripts/fetch-native-deps.sh`

### 仍不做

- Dynamic Feature、4GB 视频、PDF 水印、更多输出格式
- 「更多跨设备测试」没有第二台真机，本版不扩

## 安装摘要

1. 只要图片 / 音视频 / PDF / 压缩包 → 装 Basic。还要 Word / PPT / Excel 转 PDF → 装 Office。
2. 用 Release 附件里的 `SHA256SUMS.txt` 核对哈希。
3. 允许「安装未知应用」后打开 APK。
4. 从 v1.1.0 升级：直接覆盖。从 v1.0.0 升级：先卸载再装。

## 已知问题

- 仅 arm64-v8a
- 已装旧证 v1.0.0 无法被本版覆盖
- Dynamic Feature、4GB 视频仍按产品决定延期
