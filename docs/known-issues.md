# OpenConvert 1.0 已知问题

面向使用者与发行说明。工程缺口的完整对照见 `docs/v1.0-roadmap-gap.md`。

## 发行范围

- **只提供 arm64-v8a。** 32 位机和多数官方模拟器装不上。
- **双 Edition，不是动态功能模块。** Basic 不含 LibreOfficeKit。商店内按需交付应走 Play Feature Delivery / split APK，不要使用已确认崩溃的 `files/` 动态加载。
- **v1.0.0 同 versionCode。** 已发布的 `1.0.0` Basic / Office 都是 `100`，图形安装器可能拒绝同版本覆盖。`1.1.0` 起 Basic / Office 差 1（1100/1101，1.2.0 为 1200/1201），同证时图形安装器可直接 Basic → Office。旧证覆盖仍只适用于已装 1.0.0。
- **签名口令曾进入 git 历史**，必须视为已泄露。jks 本身从未入库。v1.0.0 仍是旧证 `65776a27…`；**v1.1.0 起用 v2 证** `887ce064…`，已装 1.0 不能覆盖升级，需卸载重装。见 `docs/signing-audit.md`。

## 能力边界

- 图片 **编码** 只有 JPG / PNG / WEBP。AVIF、HEIC、GIF、BMP、TIFF 可以读入，不能作为输出格式。
- Office → PDF 已覆盖中文、复杂/合并表格、页眉页脚、多页/多 Sheet 与公式结果；**图表、嵌入对象、受保护文档**未做内容级门禁，复杂版式可能与桌面 LibreOffice 有差异。
- PDF **水印**未做。
- 批量页只能套用已有预设，不能在批量草稿上新建预设（单文件配置页可以新建）。
- 任务卡速度是按进度比例估算，不是真实字节计数。
- Benchmark 只采集 SINGLE 任务；不采集 CPU（Android 只能稳定拿到整进程值）；多输入工具类任务暂不写入。

## 设备与权限

- 后台通知权限在 Android 13+ 必须由用户点一次「允许」；`adb grant` 在部分机型会被系统拒绝。
- 大文件转换前会按约 2 倍临时空间预检。空间不足会拒绝，而不是写到一半失败。
- 100 MB–4 GB 梯度的超长稳定性、系统杀进程矩阵、Android 12–15 / 多 SoC 字体差异尚未铺开。

## 不要当作故障

- 状态栏出现网络图标，是系统状态，不是应用在联网。应用 Manifest 不声明 `INTERNET`。
- Basic 里看不到 Office → PDF，是产品边界，不是漏装资源。
- 同编码音视频走流拷贝时几乎不重编码，耗时会明显短于「转码」预期。
